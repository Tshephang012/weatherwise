MEET WEATHERWISE

Weather information made simple.

WeatherWise is a student weather application designed to make everyday weather information clear, accessible and personal.

What you can do

  • Search for cities around the world.
  • Choose a matching location before requesting weather.
  • View current conditions and upcoming forecast intervals.
  • Switch between Celsius and Fahrenheit.
  • Choose which measurements appear.
  • Set an in-app high-temperature alert.
  • Revisit the latest saved weather when offline.

How to get started

  1. Create an OpenWeather account and obtain an API key.
  2. Enter your key on the Settings page.
  3. Return to Home and search for a city.
  4. Select the correct location from the search results.
  5. Open Weather Details to explore the forecast.

Weather data and limitations

Weather information is supplied by OpenWeather.

Current conditions and forecasts are different products. Forecast values are predictions and can change. Always check the observation and retrieval times.

WeatherWise's temperature messages are personal threshold checks, not official severe-weather warnings or emergency advice.

Offline access

After a successful online visit and service-worker installation, the application can load its cached pages offline. The latest successfully saved weather can also be displayed.

You cannot retrieve new weather or search for new locations offline. Saved weather is labelled with its retrieval time. Browser storage can be cleared or unavailable.

Privacy and storage

Display preferences and the latest weather result are stored locally in your browser. Your API key is stored in this tab's session storage.

Searches contact OpenWeather directly. The homepage comment form is a demonstration: it neither sends nor stores your comment, name or email address.

This frontend demonstration does not hide API credentials from the browser. A production version should protect credentials through a server-side service.
